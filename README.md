# StockAI - Real Time Stock Price Movement Prediction

##  Live Demo

https://stockai-b83p.onrender.com

##  Features

- Real-time stock price tracking
- XGBoost-based stock prediction
- NLP sentiment analysis from news
- Interactive stock charts
- User authentication (Login/Register)
- Analytics dashboard
- Prediction history
- CSV export

##  Tech Stack

- Python
- Flask
- XGBoost
- Pandas
- Scikit-Learn
- NLTK
- Plotly
- SQLite
- Render
